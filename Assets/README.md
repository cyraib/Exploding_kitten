# Asset library

Start with the [deck catalog](decks/README.md) for all 11 requested versions and their card quantities, rules, and asset links.

- [cards/](cards/README.md): original icons and artwork, shared by card family.
- `decks/<edition-or-expansion>/`: original box/logo, `rules.pdf`, and edition reference files.
- `decks/exploding-kittens-recipes-for-disaster/recipes/`: official online ingredient tables and source-conflict notes.
- [components/](components/README.md): accessory illustration.
- `site-ui/`: original site branding and UI images.
- [manifest.json](manifest.json): source URLs, updated paths, original paths, byte sizes, and SHA-256 hashes.

Original bytes are preserved. Artwork counts are not card quantities. Assets are shared by card family; edition-specific printed-art assignments have not been established. [Migration map](../.codex/asset-path-migration.json) maps every old downloaded path to its new location.
