## Sources and mapping limits

Counts are checked against the supplied [rulebook](https://dumekj556jp75.cloudfront.net/recipes-for-disaster/RFD_instructions.pdf) and the [deck inventory](https://explodi.ng/decks/exploding-kittens-recipes-for-disaster). The PDF supplies effect rules and family totals; the website supplies named cat identities and their individual counts/paw split. Recipes for Disaster also uses the official supplementary field guide. Empty paw fields are represented as zero.

Artwork is stored once in `Assets/cards/` and linked here. A family may contain artwork from multiple editions. The number of artwork images is not the number of physical cards; no unverified edition-specific image-to-copy assignment is claimed. Cat artwork is matched by its named identity. These downloaded images do not constitute a complete verified scan of each edition.

## Edition notes

- Exact scans of all 13 printed recipe booklets are not included in the supplied main PDF; the supplemental online catalog may differ and contains flagged source conflicts.
- Shared card artwork is not a verified print-by-print Recipes for Disaster scan.
