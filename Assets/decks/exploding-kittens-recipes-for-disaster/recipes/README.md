# Recipes for Disaster - official online recipes

These are supplementary online setups, not a verified reconstruction of all 13 printed booklets in the 2021 box. Card names are normalized; original ingredient labels are retained in JSON. Empty player lists mean that setup is not supplied. The online source does not encode every possible printed special instruction. Use a printed booklet if it disagrees.

Source: [official recipe selector](https://www.explodingkittens.com/pages/recipes). Retrieved 2026-10-04.
