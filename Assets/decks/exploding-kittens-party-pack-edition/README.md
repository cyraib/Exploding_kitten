## Sources and mapping limits

Counts are checked against the supplied [rulebook](https://dumekj556jp75.cloudfront.net/ek-party-pack/EK_Party_Pack-Rules_wAttack.pdf) and the [deck inventory](https://explodi.ng/decks/exploding-kittens-party-pack-edition). The PDF supplies effect rules and family totals; the website supplies named cat identities and their individual counts/paw split. Recipes for Disaster also uses the official supplementary field guide. Empty paw fields are represented as zero.

Artwork is stored once in `Assets/cards/` and linked here. A family may contain artwork from multiple editions. The number of artwork images is not the number of physical cards; no unverified edition-specific image-to-copy assignment is claimed. Cat artwork is matched by its named identity. These downloaded images do not constitute a complete verified scan of each edition.
