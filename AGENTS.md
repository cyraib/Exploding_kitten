# Project instructions

At the start of every new chat or task in this project, read [memory.md](memory.md) first to catch up with the current status. Use its linked `.codex/` notes for details, and verify relevant files before relying on the snapshot.
After each task or feature, append its request, changed files, outcome, validation, and remaining limitations to `memory.md` in English.
Keep feature notes and supporting scripts in `.codex/`, and link them from `memory.md`.
Keep `.codex/memory.md` as a navigation link to the root log rather than duplicating the log.
Preserve original downloaded assets and record their source URLs.
